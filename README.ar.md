# مركز بروكسيات تيليجرام

دليل مستقل ثنائي اللغة (عربي/إنجليزي) لاكتشاف بروكسيات **Telegram MTProto** والتحقق من توفرها والاتصال بها. المشروع **دليل روابط فقط**، وليس خادم بروكسي: لا يمرّر حركة المرور، ولا يتطلب حسابًا، ولا يجمع بيانات تلغرام.

> المشروع غير تابع لتلغرام ولا معتمد منه. فحص التوفر ليس تدقيقًا أمنيًا، ولا نوصف أي بروكسي بأنه مجهول تمامًا أو آمن بنسبة 100%.

## ما الذي يتضمنه المشروع

- واجهة إنتاجية بـ React 19 وTypeScript وVite وTailwind CSS v4، مع أيقونات Lucide وحركات Framer Motion وخطوط مستضافة ذاتيًا.
- عربية RTL وإنجليزية LTR بالكامل، مع حفظ اللغة، ومعالجة صحيحة للاتجاه في العناوين والمنافذ والمفاتيح.
- وضعان فاتح وداكن يُحفظان ويُطبقان قبل أول رسم للصفحة.
- دليل بروكسيات مع بحث فوري وفلاتر (الحالة، الدولة، الثقة) وترتيب (الأسرع، الأحدث، الاسم)، ومزامنة الفلاتر مع الرابط، وحالات تحميل وفراغ وخطأ.
- صفحة تفاصيل: سجل التوفر، آخر الفحوصات، رابط t.me الرسمي، نسخ العنوان والرابط، إظهار المفتاح المقنّع، شرح الثقة والمراقبة.
- نموذج بيانات صارم: تحقق، منع التكرار، رفض العناوين الخاصة، فصل التوفر عن الثقة، وعدم اختراع أي بروكسي.
- مراقبة واعية بـ MTProto عبر GitHub Actions: مصافحة obfuscated2 ثم `req_pq_multi` وتوقع `resPQ` مع تطابق nonce، مع تسجيل الاستجابة والسجل.
- قائمة أفضل 12 تلقائية: مجمّع مجدول يجلب المصادر العامة المعتمدة، ويتحقق فعليًا من المفاتيح العادية وFake-TLS (`ee…`)، ويرتب المؤكد فقط، وينشر `data/top-proxies.json` دون حشو مراكز ناقصة. التفاصيل في [docs/COLLECTOR.md](./docs/COLLECTOR.md).
- إدارة مصادر موثقة، واستيراد المرشحين إلى قائمة مراجعة غير منشورة (`data/candidates.json`).
- إرسال مجتمعي: تحقق محلي، منع تكرار، حد معدل، فخ روبوتات، موافقة صريحة، ونموذج GitHub Issue. لا نشر تلقائي.
- SEO واستضافة: قوالب مسارات مسبقة، canonical وOG وTwitter وJSON-LD، sitemap، robots، رؤوس أمان، وإعداد Cloudflare Pages.
- إتاحة: رابط تخطي، معالم صفحة، تنقل لوحة المفاتيح، حالات تركيز، ARIA، أهداف لمس 44px، ودعم تقليل الحركة.

## البدء السريع

المتطلبات: **Node.js 22+** وnpm.

```bash
npm install
npm run dev          # يزامن البيانات العامة ثم يشغّل Vite
npm run build        # فحص الأنواع + مزامنة + بناء + SEO
npm run preview      # معاينة ./dist
```

المستودع يأتي **بقاعدة بيانات فارغة** عن قصد: لا توجد بروكسيات وهمية لملء الواجهة. أضف إدخالات موثقة قبل النشر، أو انشر الدليل فارغًا وافتح باب الإرسال.

## إضافة بروكسي بشكل آمن

1. سجّل المصدر في `data/sources.json` بعد مراجعة شروطه وحق إعادة النشر.
2. أضف نقطة نهاية موثقة:

```bash
npm run proxies:add -- \
  --server relay.example.net --port 443 \
  --secret <32-or-more-even-hex-characters> \
  --source manual --name "Example relay" --country DE --trust community
```

3. تحقق:

```bash
npm run validate:proxies
npm run monitor:proxies
```

4. راجع الفرق في `data/proxies.json` ثم ارفعه وانشر. البناء يعيد نشر `public/data/proxies.json` تلقائيًا.

الحقول أعلاه توضيحية فقط؛ النطاقات المثال مرفوضة من التحقق ولا تظهر كبروكسيات عاملة. التفاصيل الكاملة في [docs/DATA-SCHEMA.md](./docs/DATA-SCHEMA.md).

## المراقبة

`.github/workflows/monitor.yml` يعمل كل ساعتين ويمكن تشغيله يدويًا. الفاصل الزمني مقصود للاستخدام المجاني لـ GitHub Actions ويمكن تعديله. يقوم بـ:

1. التحقق من قاعدة البيانات.
2. فحص كل نقطة منشورة مرة واحدة بمصافحة MTProto واعية (obfuscated2 + `req_pq_multi` ثم `resPQ` بـ nonce مطابق).
3. تسجيل `online` أو `offline` أو `timeout` أو `unknown`، والاستجابة، وآخر نجاح، وحتى 48 نقطة سجل.
4. عمل commit فقط عند تغيّر `data/proxies.json` فعليًا.

| المتغير | الافتراضي | النطاق | الوظيفة |
| --- | --- | --- | --- |
| `PROXY_MONITOR_TIMEOUT_MS` | `8000` | 1500–30000 | مهلة كل فحص |
| `PROXY_MONITOR_CONCURRENCY` | `4` | 1–10 | عدد الفحوص المتوازية |
| `PROXY_MONITOR_FAILURE_THRESHOLD` | `2` | 1–10 | عدد الفشل المتتالي قبل offline/timeout |

حدود معلنة:

- مفاتيح fake-TLS (تبدأ بـ `ee`) تُفحص بمصافحة TLS ClientHello والتحقق من ServerHello HMAC ثم مصافحة obfuscated2 نفسها؛ المصافحة غير المؤكدة تبقى **unknown** ولا تُعدّ متصلة أبدًا.
- الفحص الفاشل يبقى `unknown` حتى بلوغ حد الفشل؛ لا يخمّن السكربت `online`.
- الفحص دليل استجابة آنية، وليس تدقيقًا أمنيًا أو مراجعة تشفير أو خلفية للمشغّل.
- لا يُفحص إلا ما نُشر من مصادر مراجعة؛ السكربت ليس ماسحًا للشبكة.

## قائمة أفضل 12 تلقائية

`npm run collect:proxies` يجلب المصادر المدرجة في `config/collector.json`، يتحقق منها ويزيل التكرار، يفحص كل نقطة بمصافحة MTProto حقيقية (بما فيها مفاتيح Fake-TLS `ee…`)، يرتب المؤكد فقط، ثم ينشر أفضل عشرة في `data/top-proxies.json` كتابةً ذرّية. استخدم `npm run collect:proxies:dry` لمراجعة الترتيب دون كتابة ملفات. يشغّل `.github/workflows/collect.yml` الأمر نفسه كل ساعتين ويعمل commit فقط عند تغيّر الملفات. الموقع يقرأ الناتج الثابت ولا يفحص أي بروكسي في المتصفح. الإعداد والحالة وسلوك الفشل والأوزان موثقة في [docs/COLLECTOR.md](./docs/COLLECTOR.md).

## الإرسال المجتمعي

نموذج `/submit` يتحقق محليًا، ويكشف التكرار مقابل قاعدة البيانات وطابور المتصفح، ويطبق حدًا 10 دقائق وفخ روبوتات. عند ضبط `VITE_REPO_URL` يفتح GitHub Issue معبأة مسبقًا بالقالب المنظم؛ وإلا يوضح أن الإرسال المباشر غير مهيأ ويعرض نسخ بيانات الطلب. الطلبات المعلّقة لا تظهر في الدليل ولا تُكشف بيانات اتصالها.

## متغيرات البيئة

كل متغير يبدأ بـ `VITE_` عام ويظهر في حزمة المتصفح. لا تضع فيه رموزًا أو مفاتيح خاصة.

| المتغير | مطلوب | الوصف |
| --- | --- | --- |
| `VITE_SITE_URL` | يُنصح | أصل الموقع بلا شرطة أخيرة، لبيانات SEO وsitemap وrobots |
| `VITE_REPO_URL` | يُنصح | رابط المستودع العام، يفعّل الإرسال عبر Issues |
| `VITE_DATA_URL` | اختياري | رابط بعيد لـ `proxies.json`؛ أضف نطاقه إلى `connect-src` في `public/_headers` |
| `VITE_CONTACT_EMAIL` | اختياري | بريد تواصل عام في صفحة «حول» |

## الاختبار

```bash
npm run typecheck
npm test
npm run validate:proxies
npm run build
```

تغطي الاختبارات التحقق من الخادم والمنفذ والمفتاح، ونطاقات IPv4 المحجوزة، ومنع التكرار، وقراءة قاعدة البيانات، والفلاتر والترتيب والإحصاءات، والتنسيق، وتطابق القواميس العربية والإنجليزية.

## النشر على Cloudflare Pages (مجانًا)

1. ارفع المشروع إلى مستودع GitHub.
2. أنشئ مشروع Cloudflare Pages مرتبطًا بالمستودع.
3. أمر البناء: `npm run build`، ومجلد الإخراج: `dist`.
4. اضبط `VITE_SITE_URL` و`VITE_REPO_URL` واختياريًا `VITE_DATA_URL` و`VITE_CONTACT_EMAIL`.
5. انشر.

التفاصيل الكاملة في [docs/DEPLOYMENT.md](./docs/DEPLOYMENT.md).

## الأمان والخصوصية

- يُخزَّن محليًا تفضيل اللغة والوضع فقط. راجع `/privacy`.
- مفاتيح MTProto **عامة بطبيعتها** لأنها جزء من رابط الدعوة، لكنها تبقى خارج السجلات ومخرجات المراقبة.
- لا جمع لحسابات تلغرام أو كلمات المرور أو رموز الدخول، ولا أدوات تتبع.
- التوفر ليس ثقة؛ اقرأ `/security` قبل الاتصال.
- للإبلاغ عن ثغرة اتبع [SECURITY.md](./SECURITY.md).
